# NTE Bond Guide

A bond guide for Neverness to Everness. Made by Shikaru.

- **Cost Guide** — the cheapest 100-, 200- and 400-bond gift for every character, where to buy it, and how many gifts, days and Fons it takes to go from bond 0 to max. Toggles for Zero's life skill, daily dating, the free Fluffy Cloud, and one-time quests & gestures.
- **Free Bond Priority** — every character ranked by gift cost, so you know who to spend free clouds and dates on to save the most Fons.

## Use it

Open `index.html` in a browser. No build step or server needed. To publish it, push this folder to a repo and turn on GitHub Pages (Settings → Pages → deploy from the branch root).

## What's inside

```
index.html            the page (styles and logic inline)
data/                 characters, gift picks, the full shop catalog, icons, bond math
assets/icons/         character portraits and every catalog item's icon
tools/check.js        checks the data for mistakes: node tools/check.js
MAINTAINING.md        how to add characters and items, and how gift picks are chosen
```

To add a character, add or reprice an item, or update after a patch, follow [MAINTAINING.md](MAINTAINING.md). Toggle settings are saved in your own browser only.
